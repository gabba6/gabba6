### 🔥 Now in public beta: Flammy

**Flammy: Focus & Screen Time** — an iPhone app that helps you spend less time on your phone. You decide which apps are blocked and when; before you open one anyway, Flammy (a little flame that grows when you focus) gives you a short, friendly pause. Uses Apple's Screen Time APIs, all data stays on your device.

**[Join the beta on TestFlight →](https://testflight.apple.com/join/6SyuFbkw)** · [Privacy](https://gabba6.github.io/flammy-privacy/)

Feedback and ideas are very welcome — take a screenshot in the app and choose *Send Beta Feedback*.

### Featured projects

**[Agent iPhone Kit](https://github.com/gabba6/agent-iphone-kit)** — lets AI coding agents drive a real iPhone over USB in short, token-efficient steps and measure UI animations at 60 fps with real device timestamps. Builds on Callstack's open-source [agent-device](https://github.com/callstack/agent-device) and adds interaction patterns measured on a real device, a native screen recorder with motion and easing analysis, and a lean MCP server. Built with AI assistance using Node.js and Swift, with benchmarks, automated tests and documented limitations.

**[Agent Limit Watchdog](https://github.com/gabba6/agent-limit-watchdog)** — a macOS tool that monitors Claude Code and Codex usage limits, warns before limits are reached, and helps pause and resume supported sessions. Built with AI assistance using Python and SwiftUI, with documented limitations, automated tests and setup instructions.
